# Sentiment Analysis

## Objective
To analyze textual data and classify user opinions as positive or
negative using Natural Language Processing techniques.

## Dataset
The dataset contains text reviews and corresponding sentiment labels.

## Steps Performed
- Data cleaning and preprocessing
- Text vectorization using TF-IDF
- Sentiment classification using Naive Bayes
- Model evaluation using accuracy and classification report

## Tools Used
- Python
- Pandas
- Scikit-learn

## Conclusion
Sentiment analysis helps organizations understand user feedback
and make data-driven improvements.
