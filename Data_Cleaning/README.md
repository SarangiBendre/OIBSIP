# Data Cleaning Project

## Objective
The objective of this task is to clean raw data by handling missing
values, duplicate records, incorrect data types, and invalid values
to improve data quality for analysis.

## Dataset
The dataset contains raw data with potential issues such as:
- Missing values
- Duplicate records
- Incorrect data types
- Invalid values

## Cleaning Steps Performed
- Identified and removed missing values
- Removed duplicate records
- Corrected data types
- Handled invalid and inconsistent values
- Saved cleaned dataset for further use

## Tools Used
- Python
- Pandas
- NumPy

## Output
A cleaned dataset (`cleaned_data.csv`) ready for analysis or modeling.

## Conclusion
Data cleaning is a crucial step in data analytics that ensures
accurate insights and reliable model performance.
