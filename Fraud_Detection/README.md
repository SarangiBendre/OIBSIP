# Fraud Detection Using Machine Learning

## Objective
The objective of this project is to detect fraudulent transactions
using machine learning techniques by analyzing transaction patterns
and customer behavior.

## Techniques Used
- Data preprocessing
- Exploratory Data Analysis
- Feature selection
- Machine Learning classification models
- Model evaluation

## Tools
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
