# Customer Segmentation Analysis

## Objective
The objective of this project is to segment customers based on their
purchasing behavior using clustering techniques. This helps businesses
understand different customer groups and design targeted strategies.

## Techniques Used
- Data preprocessing
- Feature selection
- K-Means clustering
- Visualization of customer segments

## Tools
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
